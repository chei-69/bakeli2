Développement Web (Front-End)

↑ Retour aux formations
  • Durée : Entre 6 mois et 12 mois, pour ceux qui ont des bases en informatique

Vous allez apprendre à :

  • Intégrer des applications web
  • Rédiger des tests unitaires et fonctionnels
  • Rédiger un cahier des charges
  • Déployer des applications en ligne
  • Interagir avec des clients
  • Travailler à plusieurs dans un projet

Vous allez utiliser :

Les langages :

  • HTML5
  • CSS3
  • JavaScript
  • TypeScript

Les frameworks :

  • Bootstrap
  • React JS

Vous pouvez devenir :

  • Développeur web - Front end (Spécialité React Js)
  • Intégrateur web (Spécialité Bootstrap et React Js)

Modules du cours :

  1. Introduction au Développement Web
  2. HTML et CSS
  3. JavaScript Fondamental
  4. Frameworks JavaScript
  5. Conception et UX
  6. Développement Responsive

Community Management

↑ Retour aux formations
  • Durée : 6 mois ou 12 mois, en alternance école / entreprise
  • Diplôme préparé : CPS (Certification Professionnelle de Spécialisation)
  • Nombre de places : 30

Vous allez apprendre à :

  • Créer des plans marketing
  • Créer un calendrier éditorial
  • Créer des images et vidéos
  • Créer des sites web
  • Rédiger des articles
  • Gérer et animer des communautés en ligne

Vous allez utiliser :

  • Google Drive
  • Canva
  • CapCut
  • Jitter
  • Meta Business Suite
  • Figma
  • Inkscape
  • Gimp

Vous pouvez devenir :

  • Community manager
  • Social media manager
  • Copywriter, Ghostwriter
  • Infographiste

Modules du cours :

  1. Introduction au Community Management
  2. Communication et Engagement
  3. Création de Contenu
  4. Gestion de Communauté en Ligne
  5. Gestion de Crises
  6. Stratégies Avancées et Tendances Émergentes
